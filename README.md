# Cola City Cats Website

## What's included
- Responsive one-page website
- Home, About Us, Current Kittens, FAQ, Contact
- Cola City Cats vector logos
- Waffles photos
- Editable kitten data in `assets/js/kittens.js`
- Mobile navigation
- SEO metadata
- GitHub Pages-ready structure

## Before launch
1. Replace the six placeholder kitten images in `assets/images/` with the real kitten photos.
2. Edit `assets/js/kittens.js` to add names and availability.
3. Create a free Formspree form and replace `YOUR_FORM_ID` in `index.html`.
4. Update `sitemap.xml` and `robots.txt` if your final domain differs from `www.colacitycats.com`.

## Local preview
Open `index.html` directly in a browser, or use a local server such as VS Code Live Server.

## GitHub Pages
Create a GitHub repository named `cola-city-cats` (or another name you prefer), upload all files, then enable Pages from the repository's Settings > Pages and select the main branch.

## Cloudflare
Once GitHub Pages provides the Pages URL, we'll add the custom domain in GitHub Pages and configure the required DNS records in Cloudflare. Keep Cloudflare SSL/TLS mode on Full/Strict after the domain is connected.
